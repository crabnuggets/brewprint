## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues. Before tracker operations, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before triaging, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout. Before exploring the codebase, read `docs/agents/domain.md`.

### Releases

Every PR needs exactly one label: `release: fix`, `release: feature` or `release: breaking`. Add it when filing the PR. A release is a tag on `main`, and only the owner decides to release. Before labeling a PR, tagging, choosing a version number, or changing the release workflows, read `docs/agents/releasing.md`.

### UI work

Before implementing or reviewing UI, read `docs/ui-design.md`, `docs/ux.md`, and `docs/design/mockups/README.md`. Visually inspect the relevant mockup PNGs linked there.
